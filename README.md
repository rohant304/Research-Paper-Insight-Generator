# Research Paper Insight Generator

An AI-powered application that helps users quickly understand research papers by extracting important information.

## Features

- Abstract extraction
- Methodology extraction
- Findings extraction
- Conclusion extraction

## Technologies

- Python
- LangChain
- Gemini API
- Streamlit
- NLP

# Dataset

ArXiv Research Papers

## Project Goal

To provide a quick and simple way to understand research publications.
